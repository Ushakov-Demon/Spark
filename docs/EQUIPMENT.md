# Каталог оборудования

Всё, что можно поставить на стол экспериментатора, — данные в `src/equipment/`. Физика не знает о конкретных предметах: она читает их спецификацию (`domains/thermal/assembly.ts`).

## Структура

```
Обладнання (CATEGORIES, src/equipment/taxonomy.ts)
├─ Прилади (device)
│  ├─ Нагрівачі (device.heater)
│  │  ├─ Побутові (device.heater.household):     електроплита, індукційна плита, газова плита, кип'ятильник
│  │  └─ Лабораторні (device.heater.laboratory): газовий пальник, спиртівка
│  └─ Вимірювальні (device.measuring)            — зарезервовано: термометр, ваги, секундомір
└─ Посуд (vessel)
   ├─ Побутовий (vessel.household):              каструля (кришка — за бажанням)
   └─ Лабораторний (vessel.laboratory):          хімічний стакан
```

Бытовое/лабораторное — уровень дерева, поэтому интерфейс группирует варианты, а задание может ограничиться лабораторным оборудованием.

## Карточка предмета (общая для всех)

| Поле | Что это |
|---|---|
| `id` | постоянный идентификатор (используется в сохранённых опытах) |
| `category` | лист дерева категорий |
| `name` | название на всех языках |
| `description` | что это и как работает — по уровням (`novice`, `school`, …) |
| `safety` | правила безопасности (необязательно) |
| `media` | изображения и 3D-модели (необязательно, см. ниже) |
| `spec` | спецификация, своя для каждого вида |

## Спецификации

- **Нагреватель** (`HeaterSpec`): способ нагрева (`contact` / `flame` / `induction` / `immersion`), ручка или выключатель, модели по мощности, минимальное пламя, доля тепла в посуду, требования к материалу посуды (индукция — только магнитные металлы), собственное тело (масса, площадь) и контакт с посудой.
- **Посуда** (`VesselSpec`): объёмы, материалы, пропорции, толщина стенки, модель массы, крышка.

Каждое число — `SourcedValue` с источниками, как в справочнике материалов. Если источника нет — `verification: 'estimate'` и `note`. Тесты проверяют это для каждого предмета.

## Совместимость

`canHeat(heater, vessel, material)` — только правила, подтверждённые источником (сейчас: индукция и немагнитные материалы). Несовместимая комбинация не ломает опыт: прибор просто не греет, а интерфейс объясняет почему.

## Сборка установки

`placeVessel(...)` и `placeHeater(...)` возвращают объекты и связи с заданными именами — установку собирают из кусков, в одной сцене может быть несколько приборов и сосудов. Крышка — отдельное тело (вода → воздушный зазор → крышка → комната). Стенка посуды — последовательно с теплоотдачей в воду (1/G = L/kA + 1/hA): для металла почти не влияет, для стекла заметно.

## Как добавить предмет

1. Найти данные и источники (см. [DATA_POLICY.md](DATA_POLICY.md)), добавить источник в `knowledge/sources.ts`.
2. Добавить запись в `heaters.ts` или `vessels.ts` (или новый файл для нового вида + тип в `types.ts`).
3. Описание — по [CONTENT_STYLE.md](CONTENT_STYLE.md), на `uk` и `en`.
4. `npm test`: тесты проверят категорию, данные, тексты, совместимость, сохранение энергии во всех комбинациях.

## Медиа (изображения, 3D-модели)

```ts
media: [
  { kind: 'image', src: 'gas-hob.svg', format: 'svg', alt: { uk: '…', en: '…' }, license: 'project', author: 'Spark contributors' },
  { kind: 'model3d', src: 'beaker-250.glb', format: 'glb', alt: { uk: '…', en: '…' }, license: 'CC-BY-4.0', author: '…', sourceUrl: '…' },
]
```

- Файлы кладутся в `web/public/equipment/` (или указывается полный URL).
- Обязательны: текстовое описание `alt` на всех языках, лицензия, автор; для чужих работ — `sourceUrl`.
- Лицензии — совместимые с открытым проектом (CC0, CC BY, CC BY-SA, собственные работы).
- 3D: предпочтительно `glb` (один файл), умеренный размер — страница должна открываться на телефоне.
- Тест проверяет наличие файла, лицензии, автора и `alt`.
