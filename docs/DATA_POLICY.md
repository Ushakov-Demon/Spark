# Политика данных

Ни одно число не попадает в движок «по памяти». Каждое значение — `SourcedValue` с источниками, условиями измерения и уровнем доверия. Тесты (`tests/knowledge`) проверяют, что выбранное значение действительно согласуется с источниками. `npm run knowledge:report` показывает текущее состояние.

## Уровни доверия

| Уровень | Требование (проверяется тестом) |
|---|---|
| ✅ `cross-checked` | ≥ 2 **разных** источника, все цитаты в пределах `tolerance` от значения |
| ⚠️ `single-source` | ≥ 1 согласующийся источник + `note`, почему нет второго |
| ❓ `estimate` | `note` с обоснованием; в UI показывать как «примерное значение» |

## Как добавить или изменить значение

1. Найти минимум два источника из реестра [`src/knowledge/sources.ts`](../src/knowledge/sources.ts). Новый источник сначала добавить в реестр (URL, лицензия, дата).
2. Записать **условия**: температура, фаза, сорт. Значения при разных условиях — не одно и то же (теплопроводность воды при 0 °C и 20 °C отличается на 7 %).
3. Цитировать то, что **написано в источнике**, а не округлённое значение. Диапазон — через `range`.
4. Если источник описывает другой материал (OpenStax «steel iron» — это железо, а не сталь), его не засчитывать, а пометить в `note`.
5. `npm test` и `npm run knowledge:report`.

## Источники и лицензии

| Источник | Лицензия | Что берём |
|---|---|---|
| Wikidata | CC0 | числа; **обязательно смотреть квалификаторы** (на одном объекте бывает 6 значений при разных температурах) |
| OpenStax College Physics 2e | CC BY-NC-SA 4.0 | **только числа** (факты). Тексты не копируем: ShareAlike распространится на наши тексты, а издатель запрещает обучение ИИ на книге |
| Википедия | CC BY-SA 4.0 | числа (вторичный источник, сверять с первичными, которые она цитирует) |
| Учебные программы (Украина: МОН, модельные программы НУШ) | только факты и короткие цитаты | в каком классе и насколько глубоко изучают тему (`CurriculumRef`, дословная цитата) |
| Школьные учебники | копирайт | не используем |

Проект некоммерческий. Из NC-источников (OpenStax 2e) берём только числа, это факты. Лицензия хранится у каждого источника, чтобы это всегда можно было проверить. Собственные тексты Spark — CC BY-SA 4.0, код — MIT (см. LICENSE, LICENSE-CONTENT.md).

## Тексты для школьников

Тексты пояснений пишем сами (`textSource: 'spark'`). Флаг `reviewed: false`, пока их не вычитал учитель физики. В UI неподтверждённые тексты можно скрывать или помечать.

## Исторические факты

Авторы, даты, названия работ — тоже факты с источниками (`FactCitation`): годы жизни — из Wikidata по Q-id, история — из статей с указанием раздела. Тест требует цитату Wikidata для каждого «открывателя». Если у закона нет единственного автора, ставим `role: 'associated'` — в тексте будет «Связано с именами», а не «Открыл».
